1. Limbajele C și C++ ● Începător

Un program este o listă de ordine scrise într-un limbaj pe care calculatorul (prin intermediul unui traducător numit compilator) îl poate înțelege. Înainte să scriem primul program, merită să știm de unde vine limbajul pe care îl folosim.

Limbajul C

Limbajul C a fost creat în 1972 la Bell Laboratories (Dennis Ritchie), având ca obiectiv principal dezvoltarea unui limbaj în care să fie implementat sistemul de operare UNIX. Faptul că un întreg sistem de operare a fost scris în C spune mult despre puterea lui.

Interactiv Linia timpului — apasă pe fiecare reper
1969–1972 — la Bell Labs se naște UNIX și, pentru el, limbajul C.
Ken Thompson și Dennis Ritchie aveau nevoie de un limbaj „aproape de mașină” (rapid, cu acces la memorie) dar mult mai ușor de scris decât limbajul de asamblare.
1978 — apare cartea „The C Programming Language” (Kernighan & Ritchie).
Cartea (tradusă și în română, „Limbajul C”, Ed. Teora — vezi bibliografia) a devenit standardul neoficial al limbajului, cunoscut ca „K&R C”.
1979–1983 — Bjarne Stroustrup creează „C with Classes”, redenumit C++.
Numele C++ este o glumă de programator: ++ este operatorul care mărește o variabilă cu 1. Deci C++ = „C, cu un pas mai departe”.
1989–1990 — standardul ANSI C (C89/C90); epoca compilatoarelor Borland/Turbo C++.
Codul din curs (#include <iostream.h>, void main()) provine din această perioadă: compilatoare pentru MS-DOS, unde int avea 16 biți.
1998 — primul standard internațional C++ (C++98).
Antetul devine <iostream> (fără .h), apare spațiul de nume std, tipul bool și se cere int main().
2011 → — C++11, 14, 17, 20, 23: limbajul se modernizează la fiecare 3 ani.
Bazele pe care le înveți în această unitate (tipuri, constante, cin/cout) sunt identice și în C++ modern — doar câteva detalii de „formă” diferă, iar noi le vom semnala mereu în chenare violet.

Caracteristicile limbajului C

⚡ Programe eficiente

Codul generat este rapid și ocupă puțină memorie.

🧳 Portabil

Același program sursă poate fi compilat pe sisteme diferite.

🧰 Set puternic de operatori

Aritmetici, logici, pe biți, de atribuire compusă…

🤸 Flexibilitate

Programatorul are libertate mare (și responsabilitate pe măsură).

🔩 Facilități de asamblare

Acces la adrese, la biți — lucruri specifice limbajelor de asamblare.

🧱 Limbaj structurat

Programul se împarte în funcții și blocuri clare.

Limbajul C++ — programarea orientată spre obiecte

C++ este o extensie a limbajului C: tot ce știi din C rămâne valabil, iar în plus C++ permite programarea orientată spre obiecte (programarea obiectuală).

Definiție — ObiectO entitate care cuprinde datele și procedurile ce operează cu ele. Programele sunt create ca o colecție de obiecte care interacționează, în loc de liste de instrucțiuni sau apeluri de proceduri.
De reținutÎn această unitate scriem programe „în stil C” (o singură funcție, main), dar folosind facilitățile C++ pentru citire/afișare (cin, cout). Obiectele propriu-zise vin în cursurile următoare — și, surpriză: cin și cout sunt deja obiecte!

2. Structura și sintaxa programelor C++ ● Începător

Un program C++ conține una sau mai multe funcții. Execuția începe întotdeauna cu funcția main().

2.1 Ce este o funcție?

O funcție este o secțiune de program construită folosind declarații de variabile și instrucțiuni de prelucrare. Imaginează-ți o funcție ca pe o mașinărie: primește (opțional) ceva, lucrează, și poate întoarce un rezultat — sau nu.

2.2 Funcția main() — funcția rădăcină

main() este funcția rădăcină: este prezentă în orice program C/C++, iar execuția programului începe automat cu ea. Ea poate întoarce un rezultat întreg (int) sau niciun rezultat (void).

Cel mai simplu program C++

Programul este corect, deși nu execută nimic. Pornind de la el scriem orice program, adăugând instrucțiuni între cele două acolade (corpul funcției). Cele două paranteze rotunde () se atașează oricărei funcții; între ele se scriu opțional anumiți parametri.

6.5 Tipul logic și tipul void




Obs. 3 — „tipul logic”
În C (și în C++-ul clasic din curs) nu există tipul logic: o valoare diferită de 0 este TRUE (adevărată), iar 0 este FALSE (falsă).



Obs. 4 — tipul void
În C++ este admis tipul void, cu semnificația de „nimic” sau „orice tip”, în funcție de context. Exemplu: void main() = funcția nu întoarce nimic. Nu poți declara o variabilă void.




◆ Dincolo de curs — boolDin 1998, C++ standard are tipul bool cu valorile true/false. Regula „0 = fals, orice altceva = adevărat” rămâne însă valabilă la conversii, iar cout afișează un bool ca 1 sau 0. Rulează: cout << (5 > 3); → afișează 1.

7.3 Constante caracter și secvențe escape


Constantele caracter se trec între două apostrofuri: 'a', 'A', '3'. O constantă caracter are ca valoare codul ASCII al caracterului pe care îl reprezintă: pentru 'a' se memorează 97, iar pentru 'A' se memorează 65.


O altă modalitate de scriere este sub formă de secvențe escape, care încep cu caracterul backslash (\). Fie constanta caracter 'c', cu codul 99(10) = 143(8) = 63(16). Ea poate fi scrisă echivalent: '\143' (octal) sau '\x63' (hexazecimal — precedat de x).




Rolul secvențelor escape: declararea caracterelor care nu se pot tasta. De exemplu backspace (codul 8) poate fi scris '\10' sau '\x8', iar newline (codul 10) '\12' sau '\xa'.

8. Rezumat și fișă de recapitulare




Un program C++ conține una sau mai multe funcții. O funcție este o secțiune de program construită folosind declarații de variabile și instrucțiuni de prelucrare. Funcția main() — funcția rădăcină — este prezentă în orice program C, iar execuția programului începe automat cu ea. Ea poate întoarce un rezultat întreg (int) sau niciun rezultat (void).


Pentru afișări pe ecran și citiri de la tastatură, înaintea funcției main se include fișierul antet <iostream.h> prin #include<iostream.h>. Citirile: cin>>a1>>a2>>...>>an; Scrierile: cout<<a1<<a2<<...<<an;


Orice variabilă, înainte de a fi utilizată, trebuie declarată prin precizarea tipului ei. Tipuri întregi: unsigned char, char, unsigned int, int, unsigned long, long. Tipuri reale: float, double, long double. În C++ (clasic) nu există tipul logic: o valoare diferită de 0 este TRUE, iar 0 este FALSE. Tipul void înseamnă „nimic” sau „orice tip”. O constantă se definește cu const [tip] nume = valoare; sau cu #define nume expresie.

S5 Trei baze într-o singură sumă ● Intermediar

S11 Unde „dispar” 256 de unități? ● Avansat

S12 Împărțire întreagă vs. reală ● Avansat






Rezolvare


  • a/b: ambii operanzi sunt întregi ⇒ împărțire întreagă (partea zecimală se taie): 3.
